# Encoder regulator library

TPS70950DBVR, Texas Instruments, JLC C96028, imported from public EasyEDA data
with easyeda2kicad0.8.0 and upgraded by KiCad10.0.4. `make_wrappers.py` preserves
the exact supplier part and normalizes local 3D paths. TI SBVS186H DBV pins are
1 IN, 2 GND, 3 EN, 4 NC, 5 OUT. That table was checked independently against the
import and the connected test board. Do not substitute the third-party `-TP`
part sharing a similar search name. Land patterns, paste, 3D envelope and
thermal copper still need final layout review; import success is not approval.
