# Shared passive components

Local copies of the inherited UNI-ROYAL 10 kΩ C25744 and Samsung 100 nF / 50 V C307331 atomic parts. No inherited circuit is reused. Model paths are relative to the new nested `hw/layouts/<board>/<target>` layout directories, so the original PD reference project is untouched. Symbol pin types are repaired in the native schematic generator. Land patterns and physical assembly still require prototype qualification.
